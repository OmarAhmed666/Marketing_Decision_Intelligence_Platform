# Marketing Decision Intelligence Platform

A decision-support system that helps a marketing manager choose which customers a campaign should reach, so budget goes to customers whose behavior the campaign actually changes, not to those who would have bought anyway. It combines data engineering, analytics, and machine learning (including uplift modeling).

**User:** an in-house CRM / marketing manager at one mid-sized online retailer.

**Version 1 scope:** one decision, which customers receive this week's campaign and which are deliberately left out ("send nothing" is always a valid choice). Offer and channel selection come in later versions.

**Status:** Phase 0 (problem definition and data strategy). Currently choosing the datasets.
